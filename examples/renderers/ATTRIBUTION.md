# Ferris model

Created by **Vinicius Donatto Morgado** ([viniciusmorgado](https://github.com/viniciusmorgado)).

File: `assets/ferris.glb`

The model is included without modifying the supplied GLB. The renderers apply
node transforms, center and scale geometry in memory, and use classical lighting
with the base-color texture and vertex normals.
